**Flutter AI Chat App**

Welcome to Flutter AI Chat App – a smart, AI-powered chat experience built using Flutter and Dart,
integrated with Google Gemini AI API. 🚀

**🎯 Features**

✅ AI-Powered Conversations – Seamless interaction with AI.
✅ Chat History – Keeps track of past messages.
✅ Modern UI – Clean and responsive design.
✅ Real-time Interaction – Fast message processing.
✅ Error Handling – Displays errors only when necessary.

**🔧 Installation & Setup**

**Prerequisites**

Make sure you have the following installed:

- Flutter (Latest version) → Download
- Dart SDK 
- Android Studio or VS Code
- Google API Key (for AI Integration)
  
Clone the Repository

git clone https://github.com/YOUR_GITHUB_USERNAME/Flutter-AI-Chat.git
cd Flutter-AI-Chat

Install Dependencies

flutter pub get

Run the App 🚀

flutter run
